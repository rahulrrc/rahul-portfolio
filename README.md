# Rahul M Ramchandani — Data Analyst Portfolio

A personal portfolio website built to showcase my work as a Data Analyst — presented as an interactive, 3D-inspired digital experience rather than a traditional resume page.

🔗 **Live site:** - https://rahulrrc.github.io/rahul-portfolio/

## About

This portfolio is built from my actual resume as the single source of truth, covering my background, experience, projects, and skills across data analysis, SQL, Power BI, and Python.

## Features

- Immersive hero section with an interactive Three.js particle/geometry background
- Scroll-based reveal animations and smooth section navigation
- Interactive timeline for professional experience
- Project showcase with links to individual GitHub repositories
- Skills grouped by category (Data Analysis, SQL/Databases, BI Tools, Programming, etc.)
- Downloadable resume (PDF)
- Fully responsive — works on desktop, tablet, and mobile
- Respects `prefers-reduced-motion` for accessibility

## Built With

- HTML5, CSS3, vanilla JavaScript
- [Three.js](https://threejs.org/) for the 3D hero background
- Hosted on GitHub Pages
